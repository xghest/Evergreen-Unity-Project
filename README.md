# Evergreen – 2D Platformer Demo

Evergreen is a 2D platformer demo set in a **monster apocalypse**. You play as **Phea**, a survivor trying to reach the last safe haven, Evergreen. Navigate through treacherous terrain, avoid patrolling enemies, and overcome obstacles and traps to survive.

---

## 🎮 Play Online

You can play the demo directly in your browser via Unity WebGL:  
[Play Evergreen Online](https://play.unity.com/en/games/1986154f-8022-4e79-a971-4c9a905ac10c/evergreen)

---

## ⌨ Controls

- **Move:** WASD or Arrow Keys  
- **Jump:** Space  

Automatic UI pop-ups will guide you through instructions and tips during gameplay.
